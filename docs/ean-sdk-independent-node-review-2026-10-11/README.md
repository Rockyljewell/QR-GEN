## Package integrity and derivation

`derived-results.json.gz` contains a path-tokenized, explicitly derived wrapper around all original review observations and5,783 check records. The original result contained no literal host-path replacements to make; the derivation wrapper still changes its bytes. Its uncompressed hash is the derivative's hash, **not the original result hash**. `original-evidence-hashes.json` records original and derivative identities separately. This README is also a derived explanation, not the original README bytes.

`original-manifest.json` is the exact original four-file review inventory, SHA256 `8bc2d15d3f160709c2d6712a9e9bc4337d89b30c478b67f2e5e851821dfaaa66`. Those four original files remain unchanged in their original artifact location. `archived-original-review.py.gz` expands to the exact original audit source, with its original hash preserved. It is **original-host-only audit code, not a portable replay command**: it requires the original artifact layout, plans containing local input paths, extracted SDK consumer files, source caches and Pillow. It imports no SDK but would recheck the original evidence and PNG pixels if deliberately reconstructed. No full audit rerun was performed to package this report.

With a standard Node runtime, these commands use only this compact package:

```text
node verify-package.mjs
node verify-recorded-review.mjs
```

They verify file/gzip hashes and the consistency of the retained check/count records. They perform no SDK import, image decoding or barcode recognition. The second command is a compact integrity/consistency check, not a fresh independent audit of the original551 images or4,648 calls.

This evidence does not establish default CDN or arbitrary-binary compatibility, capability/cache migration, phone stability, held-out accuracy, Scandit parity or a complete issue32 fix. PNG transport verification independently checks encoded pixels; it does not re-execute the SDK image loader. The full public matrix and staged-package provenance are retained in sibling reports. Runner code follows QR-GEN's Apache-2.0 license; the packaged evidence redistributes no photographs or upstream SDK implementation.

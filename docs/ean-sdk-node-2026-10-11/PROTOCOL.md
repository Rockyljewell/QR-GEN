Retain array order and complete data,symbology,symbologyName,rawBytes,contentType,isGS1,location,frameSize,orientation,ecLevel,symbologyIdentifier. Compare complete normalized public records and order, and separately multisets of(data,symbology,rawBytes). Compare ESM/CJS parity within each package.
